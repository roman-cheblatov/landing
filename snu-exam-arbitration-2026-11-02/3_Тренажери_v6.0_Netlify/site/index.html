Що означає «засвоєно»?

Запитання вважається засвоєним після двох упевнених правильних відповідей у різних тренуваннях. Після помилки або позначки «не впевнений» запитання повертається в найближчих адаптивних тренуваннях для закріплення. Для правильних відповідей інтервал повторення поступово збільшується. Натомість пробний іспит добирає запитання випадково для окремої перевірки знань.
