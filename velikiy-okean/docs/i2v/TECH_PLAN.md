## 2. Конвейер

```
 Библия непрерывности (bible.py)
        │
 A. Референс-пакет ── hero_master (кастинг: 8 кандидатов) ─► ваш выбор
        │                └─► hero_back/walk/profile/hands/kneel… (с @hero)
        │            океан N1…D5, локации (с @layout из теста)          ─► ваше утверждение
        ▼
 B. Ключевые кадры: с героем — gemini_image3_pro (до 14 референсов, subject: human), природа — gen4_image (@place @layout)
        │   6 вариантов на кадр: первый / последний (при необходимости средний)  ─► ваш выбор
        ▼
 C. Image-to-Video (Kling 4.0 / Kling 3.0 Pro, 1080p) — 3–4 дубля на план       ─► выбор дубля
        ▼
 D. Монтаж (conform.py): подрезка in-point, ретайм ±8 %, точное число кадров на 24 к/с,
    единый грейд и зерно, затемнение и наплывы, оригинальный звук (stream copy), проверки
```

Каждая стрелка «─►» — контрольная точка с вашим решением. Без утверждённых входов следующий этап не запускается: генератор это проверяет.

## 3. Платформы: Kling и Runway

| | **Runway API** (рекомендую) | **Kling напрямую** (сайт или API) |
|---|---|---|
| Модели | Gen-4.5, **Kling 3.0 Pro / O3 / 4.0**, Veo 3.1, Seedance, генераторы изображений — всё по одному ключу | Kling 3.0 / O3 / 4.0 и Kling Image |
| Kling 4.0 | `kling_4`: 3–30 с, `auto_1080p`, первый + до 8 средних + последний кадр, до 10 референсов, референс-видео | то же. В веб-интерфейсе есть «Elements» (сохранённые персонажи) |
| Kling 3.0 Pro | `kling3.0_pro`: 1920×1080, 1–15 с, первый и последний кадр, `cfgScale` | то же |
| Gen-4.5 | 2–10 с, **только 1280×720**, только первый кадр | — |
| Сохранение персонажа | референсы Kling 4.0 + ключевые кадры с `@hero` (gen4_image) | Elements / Omni Reference + ключевые кадры |
| Автоматизация отсюда | да: скрипт `src/i2v/runway_gen.py`, журнал расходов, лимит бюджета | API отдельный, пакеты кредитов; Elements удобнее руками в веб-интерфейсе |
| Цена (официальная) | $0,01 за кредит; Kling 3.0 Pro **$0,12/с**; Kling 4.0 1080p **$0,188/с** по акции до 30.11.2026 (обычная $0,235/с); Gen-4.5 $0,12/с | подписки от $10 до $180 в месяц (660–26 000 кредитов), цена секунды сопоставима, но зависит от тарифа и акций |

**Вывод.** Работаем через Runway API: один ключ, обе модели (Kling и Runway), полная автоматизация с контролем расходов. Основная видеомодель — **Kling 4.0** для планов с героем (референсы и ключевые кадры держат персонажа) и **Kling 3.0 Pro** для чистой природы (дешевле, нативное 1080p). **Gen-4.5** используем только для A/B-сравнения по воде на 2–3 планах: у него 720p, нужен апскейл.

Минимальное пополнение Runway API — $10. Кредиты API и подписки приложения не пересекаются.

## 4. Как держим непрерывность

1. **Кастинг героя:** один `hero_master`, остальные референсы героя — производные от него.
2. **Дословно одинаковые описания** героя, света, камеры и запретов во всех промптах (`src/i2v/bible.py`).
3. **Ключевые кадры** первого и последнего кадра каждого плана генерируются как фото со всеми утверждёнными референсами героя (gemini_image3_pro держит до 5 «человеческих» референсов), локации и композиции из теста. Видео интерполирует между утверждёнными картинками, поэтому персонаж и свет не «уплывают».
4. **Драматургия на нашей стороне:** герой в основном со спины, в профиль и силуэтом. Это сильно снижает риск дрейфа лица. Лицо — только один план профиля в контровом свете (32).
5. **Непрерывность костюма:** мокрый низ пальто с плана 13, брюки с 22, пальто до пояса с 31. Это прописано в промптах и в референсах `hero_kneel`.
6. **Свет и вода:** утверждённые референсы океана N1–D5 подаются в каждый план своего состояния.
7. **Монтаж:** единый грейд и зерно поверх всех дублей сглаживают различия между генерациями.

## 6. Риски и как с ними работаем

| Риск | Мера |
|---|---|
| Дрейф лица и костюма между планами | кастинг + производные референсы + ключевые кадры; лицо почти не показываем |
| Неточный момент события (луна выходит на 16,0 с, солнце на «дан») | первый и последний кадр задают состояние; выбор дубля; ретайм до ±8 %; для 03 и 34 — средний кадр Kling 4.0 |
| «CGI-вода», неестественная пена | референс `swash_foam`, описания физики в промптах, A/B Gen-4.5, отбраковка |
| Сложные движения (09: спуск с высоты в профиль) | запасной вариант: две склейки (указано в промптах) |
| Модерация и отказы модели | вымышленный персонаж, без брендов; отказ = замена формулировки |
| Частота кадров генерации не 24 | `conform.py` приводит к 24 к/с и точному числу кадров плана |
| Изменение цен после 30.11.2026 | бюджет посчитан и по обычной цене Kling 4.0 |

## 7. Что нужно от вас

1. **Разрешение и лимит на тест** — предлагаю $55. Генератор не потратит больше лимита: проверка по журналу перед каждым запуском.
2. **Ключ Runway API.** Создайте его в developer-портале Runway, пополните на сумму лимита и добавьте в настройках окружения этой облачной сессии (меню окружения в заголовке сессии → Edit → Network secrets или переменные окружения) под именем **`RUNWAYML_API_SECRET`**. Новая сессия его подхватит. Пожалуйста, не вставляйте ключ в чат.
3. **Кастинг:** после первого шага я пришлю 16 кандидатов `hero_master`, вы выбираете героя. Если хотите реального актёра — нужна его фотография и согласие; тогда `hero_master` строится от неё.
