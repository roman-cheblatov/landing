# Великий Океан — Тихое возвращение (музыкальный фильм)

Авторский музыкальный фильм на песню Романа Ангелиса «Великий Океан — Тихое возвращение» (5:37.52). Формат 16:9, 1920×1080, 24 к/с, оригинальный звук без изменений.

## Как устроено

- `src/analysis/` — анализ аудио: Demucs (вокал), pYIN (высота тона), Whisper large-v3 (пословные метки), сборка таймлайна.
- `src/storyboard.py` — раскадровка как данные → `docs/STORYBOARD.md` и `docs/shots.json`.
- `src/engine/` — процедурный рендер-движок (GLSL raymarching, офлайн на CPU через Mesa llvmpipe):
  - `shaders/world.frag` — небо, облака, луна и солнце, океан (15 волн с реальной дисперсией, накат, пена), пляж, объёмный туман, герой (SDF);
  - `shaders/dof.frag`, `shaders/final.frag` — физическая ГРИП, ACES, грейдинг, халация, зерно;
  - `hero.py` — скелет, пропорции, планирование шагов, позы;
  - `film.py` — планы фильма как функции времени аудио (камера, свет, действие);
  - `render_range.py` — рендер диапазона кадров в MP4; `assemble.py` — сведение с оригинальным звуком (stream copy) и технические проверки.

## Воспроизведение

```bash
# зависимости: python3.12 venv с numpy, moderngl, pillow (+ torch, demucs, faster-whisper, librosa для анализа)
cp "Великий Океан — Тихое возвращение.mp3" media/source.mp3
python src/engine/noisetex.py work/cache                      # процедурные текстуры шума
xvfb-run -a python src/engine/render_range.py 0 698 work/test/test_video.mp4
python src/engine/assemble.py work/test/test_video.mp4 out/test_0000-0698.mp4 --f0 0 --f1 698 --sheet test/contact_sheet.png
```

## Медиа

Репозиторий публичный, поэтому MP3 и MP4 с песней **не коммитятся** (см. `.gitignore`). Они лежат локально в `media/` и `out/`.

## План производства после одобрения теста

1. **Достроить сцены по актам.**
   - Акт I: макро-брызги с биолюминесценцией (07), замедленные волны с ускоренными облаками (08), вертикальный спуск (09), касание с кольцами и светом из глубины (11–14), базальтовый берег с ветром и брызгами (15–17), камера «на волне» (19).
   - Акт II: молочный туман без горизонта, морось и кольца, лунки-зеркала с отражениями, падающая капля (20–28), жемчужное свечение (29–31).
   - Акт III: колени в воде и мокрое пальто, восход, просвечивающие гребни, растворение силуэта в бликах, эпилог одним планом, следы, финальное кольцо и уход в свет (32–44).
2. **Доработать героя:** голову для профиля, кисти, позы (присед, колени, зачерпывание, подъём, вход в воду).
3. **Рендер посегментно, по планам.** Каждый план — детерминированная функция времени аудио, поэтому склейки стыкуются кадр в кадр. Для наплывов (19→20, 28→29) рендерим «ручки» по 36 кадров. Оценка ≈6–8 часов на этой машине.
4. **Сборка с оригинальным звуком** (stream copy) и проверки: длительность, 24 к/с, отсутствие чёрных кадров, побитовое совпадение звука, отсутствие скачков. Результат: `out/velikiy_okean_master.mp4`, облегчённая копия и контакт-лист всех 44 планов.
5. **После мастера** — вертикальный тизер 9:16 из кульминации (планы 34–39), при желании с кинетической типографикой.

## Фотореалистичное производство (Image-to-Video) — с 2026-11-03

Процедурный рендер теперь служит аниматиком и композиционным референсом. Основной фильм делается так: фотореальные ключевые кадры → Kling 4.0 / Kling 3.0 Pro через Runway API → монтаж с оригинальным звуком.

- План и бюджет: `docs/i2v/TECH_PLAN.md`
- Промпты 44 планов: `docs/i2v/SHOT_PROMPTS.md`
- Референсы: `docs/i2v/REFERENCES.md`
- Пакет первых 29 секунд: `docs/i2v/TEST_29S.md`
- Код: `src/i2v/` (`bible.py`, `shots_i2v.py`, `refpack.py`, `runway_gen.py` — по умолчанию сухой прогон, `conform.py`)
